# 完整流程测试指南

本文档提供了详细的步骤，帮助您测试公文文件号管理系统的完整审批流程。

---

## 🎯 测试目标

验证以下完整流程：

```
用户创建文档 
    ↓
上传Word文件
    ↓
提交校对（并行）
    ↓
校对人员完成校对
    ↓
提交审批
    ↓
副主任审批
    ↓
主任审批
    ↓
文件管理员审批
    ↓
系统自动发号 + 自动盖章
    ↓
验证结果
```

---

## 📋 测试前准备

### 1. 确保服务正在运行

**后端服务**（如未运行，请开启）:
```bash
cd C:\Users\Administrator\Desktop\code\fawen
python -m uvicorn app.main:app --reload
```

**前端服务**（已在运行中）:
- 已确认在运行：`npm run dev`
- 访问地址：http://localhost:5173

### 2. 数据库升级

由于alembic命令不可用，请手动执行以下SQL：

```sql
-- 连接到PostgreSQL数据库
psql -U postgres -d fawen

-- 执行以下SQL
ALTER TABLE documents ADD COLUMN IF NOT EXISTS approval_flow_id UUID;
CREATE INDEX IF NOT EXISTS ix_documents_approval_flow_id ON documents(approval_flow_id);
ALTER TABLE documents 
ADD CONSTRAINT IF NOT EXISTS fk_documents_approval_flow_id 
FOREIGN KEY (approval_flow_id) REFERENCES approval_flows(id);
```

或使用pgAdmin工具执行上述SQL。

### 3. 配置审批流程

**方式A：使用API手动配置**

```python
# 运行配置脚本
python scripts/setup_approval_flow.py
```

**方式B：通过前端界面配置**

1. 登录系统：http://localhost:5173
   - 用户名：`admin`
   - 密码：`admin123`

2. 创建审批角色：
   - 系统管理 → 审批角色管理 → 新建角色
   - 创建三个角色：
     - 副主任（level: 1）
     - 主任（level: 2）
     - 文件管理员（level: 3）

3. 创建审批流程：
   - 审批管理 → 流程管理 → 新建流程
   - 流程名称：标准公文审批流程
   - 添加三个节点（序号1、2、3）

4. 分配用户到角色：
   - 用户管理 → 编辑用户 → 分配审批角色

### 4. 配置电子印章（可选）

1. 准备一张PNG格式的印章图片（建议透明背景）

2. 访问：系统管理 → 印章管理

3. 上传印章图片

4. 配置参数：
   - 启用自动盖章：开启
   - 印章大小：1.5英寸
   - 印章位置：文档末尾

## 🧪 测试步骤

### 步骤1：创建文档

1. 登录系统（普通用户账号）

2. 进入"文档管理"

3. 点击"新建文档"
   - 标题：测试公文001
   - 文档类型：通知
   - 点击"创建"

4. ✅ **验证点**：
   - 文档创建成功
   - 状态为"草稿"
   - 自动生成草稿编号（格式：D-YYYYMMDD-XXXX）

---

### 步骤2：上传Word文档

1. 在文档详情页，点击"上传文档"

2. 选择一个.docx文件上传

3. ✅ **验证点**：
   - 上传成功
   - 可以预览文档内容

---

### 步骤3：提交校对

1. 点击"提交校对"

2. 选择3个校对人员

3. 选择校对模式：全部通过（all_pass）

4. 点击"提交"

5. ✅ **验证点**：
   - 文档状态变为"校对中"
   - 3个校对人员各收到1个校对任务
   - 编号字段已锁定
   - 校对人员可以收到通知（检查通知功能）

---

### 步骤4：完成校对

**使用校对人员账号登录，依次完成校对：**

1. 校对人1登录 → 我的任务 → 校对任务

2. 选择任务，点击"完成校对"
   - 选择：通过
   - 填写意见：校对通过，无问题
   - 提交

3. 重复步骤1-2，让校对人2和校对人3也完成校对

4. ✅ **验证点**：
   - 每个校对人员完成后，任务状态变为"已通过"
   - 全部校对人完成后，文档保持"校对中"状态（等待提交审批）
   - 审计日志记录了所有校对操作

---

### 步骤5：提交审批

**使用文档创建者账号：**

1. 回到文档详情页

2. 点击"提交审批"

3. 选择审批流程："标准公文审批流程"

4. 点击"提交"

5. ✅ **验证点**：
   - 文档状态变为"审批中"
   - 文档全部字段已锁定
   - 副主任收到审批任务通知
   - 系统记录了approval_flow_id

---

### 步骤6：副主任审批

**使用副主任账号登录：**

1. 进入"我的任务" → "审批任务"

2. 看到待审批的文档

3. 点击"审批"
   - 选择：通过
   - 填写意见：同意
   - 提交

4. ✅ **验证点**：
   - 副主任的任务状态变为"已通过"
   - 主任自动收到审批任务
   - 审批进度显示副主任节点已完成

---

### 步骤7：主任审批

**使用主任账号登录：**

1. 进入"我的任务" → "审批任务"

2. 看到待审批的文档

3. 点击"审批"
   - 选择：通过
   - 填写意见：同意
   - 提交

4. ✅ **验证点**：
   - 主任的任务状态变为"已通过"
   - 文件管理员自动收到审批任务

---

### 步骤8：文件管理员审批（触发自动发号和盖章）

**使用文件管理员账号登录：**

1. 进入"我的任务" → "审批任务"

2. 看到待审批的文档

3. 点击"审批"
   - 选择：通过
   - 填写意见：同意并发号
   - 提交

4. ✅ **关键验证点**：
   - 文件管理员的任务状态变为"已通过"
   - 文档状态自动变为"已通过"（APPROVED）
   - **系统自动分配正式文件号**（如：GW-2026-0001）
   - **系统自动在Word文档中添加电子印章**（如果已配置）
   - 文档自动解锁

---

### 步骤9：验证结果

1. 查看文档详情：
   - ✅ 状态：已通过
   - ✅ 正式文件号：GW-2026-XXXX
   - ✅ 审批完成时间：已记录

2. 下载Word文档，打开查看：
   - ✅ 文档末尾已添加电子印章图片
   - ✅ 显示盖章时间

3. 查看审批进度：
   - ✅ 时间轴完整显示所有环节
   - ✅ 每个节点的状态、处理人、意见都正确显示

4. 查看审计日志（管理员）：
   - ✅ 记录了所有关键操作
   - ✅ 包括：校对、审批、发号、盖章

## 🐛 常见问题排查

### 问题1：数据库连接失败
**解决方案**：
```bash
# 检查PostgreSQL服务是否运行
# Windows: 任务管理器 → 服务 → postgresql-x64-15

# 检查config.yaml中的数据库配置
```

### 问题2：上传文件失败
**解决方案**：
```bash
# 检查storage目录权限
mkdir -p storage/documents
mkdir -p storage/seals
```

### 问题3：自动盖章未生效
**解决方案**：
1. 检查是否已上传印章图片
2. 检查是否已启用自动盖章
3. 检查Python是否安装了python-docx库：`pip install python-docx`

### 问题4：审批任务未分配
**解决方案**：
1. 检查用户是否已分配到对应的审批角色
2. 检查审批流程的节点配置是否正确
