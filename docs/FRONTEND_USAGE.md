## 📝 功能使用指南

### 1. 登录系统

1. 打开浏览器访问 http://192.168.1.99:5173
2. 输入用户名: `admin`
3. 输入密码: `admin123`
4. 点击"登录"按钮

### 2. 首页

登录后进入首页，可以看到：
- 我的文档数量
- 校对任务数量
- 审批任务数量
- 已完成任务数量
- 快速操作按钮

### 3. 文档管理

点击左侧菜单"文档管理"

**创建文档：**
1. 点击右上角"新建文档"按钮
2. 填写文档标题
3. 填写文档类型
4. 点击"保存"

**编辑文档：**
1. 点击文档列表中的"编辑"按钮
2. 修改文档信息
3. 点击"保存"

**查看文档详情：**
1. 点击文档列表中的"查看"按钮
2. 查看文档详细信息
3. 查看校对任务和审批任务
4. 可以分配文件号（仅审批通过后）

**删除文档：**
1. 点击文档列表中的"删除"按钮
2. 确认删除

### 4. 校对任务

点击左侧菜单"校对任务"

- 查看所有分配给您的校对任务
- 点击"完成"按钮提交校对意见
- 选择"通过"或"不通过"
- 填写校对意见
- 点击"确定"

### 5. 审批任务

点击左侧菜单"审批任务"

- 查看所有分配给您的审批任务
- 点击"通过"或"驳回"按钮
- 填写审批意见
- 点击"确定"

### 6. 编号管理

点击左侧菜单"编号管理"

**编号池：**
- 查看所有编号池
- 查看编号范围、当前号码等

**编号记录：**
- 查看所有已分配的编号
- 查看编号状态（预留、已分配、已回收）
- 查看是否手动调整

**回收池：**
- 查看所有回收的编号
- 查看回收原因和回收时间
- 查看编号是否可用

### 7. 用户管理

点击左侧菜单"用户管理"（仅系统管理员可见）

- 查看所有用户列表
- 查看用户信息
- 查看用户角色
- 查看用户状态

## 🔄 文档状态流转

```
草稿 (draft)
  ↓ 提交校对
校对中 (proofreading)
  ↓ 全部通过
审批中 (approval)
  ↓ 全部通过
已通过 (approved)
  ↓
分配文件号

任何状态都可以被驳回 (rejected)
```

## 📌 常见问题

### 1. 无法登录
- 确认用户名和密码正确
- 检查后端服务是否正常运行
- 检查网络连接

### 2. 页面显示空白
- 清除浏览器缓存
- 刷新页面
- 检查浏览器控制台错误

### 3. 数据加载失败
- 检查后端服务是否正常运行
- 检查网络连接
- 查看浏览器控制台错误信息

### 4. 找不到某个功能
- 检查用户角色权限
- 确认功能是否已开发完成

## 🛠️ 服务管理

### 查看服务状态
```bash
# 查看后端服务
ps aux | grep uvicorn

# 查看前端服务
ps aux | grep vite
```

### 重启服务
```bash
# 重启后端
cd /home/wang/code/fawen
source venv/bin/activate
uvicorn app.main:app --host 0.0.0.0 --port 8000

# 重启前端
cd /home/wang/code/fawen/frontend
npm run dev
```

### 查看日志
```bash
# 查看后端日志
tail -f logs/app.log

# 查看前端日志
tail -f /tmp/frontend.log
```
