### 2. 🔴 C-02: 审批超时处理逻辑

**问题描述**: 审批超时后的处理逻辑未定义

**修复方案**:
- ✅ 为`ApprovalTask`模型添加`deadline`和`timeout_notified`字段
- ✅ 创建`ApprovalTimeoutService`服务,支持4种超时策略:
  - `auto_approve` - 自动通过
  - `auto_reject` - 自动驳回
  - `escalate` - 升级给系统管理员
  - `notify_only` - 仅发送通知(默认)
- ✅ 实现提前提醒机制(提前7天、3天、1天)
- ✅ 创建定时任务脚本`check_approval_timeout.py`
- ✅ 添加审批超时相关的审计事件类型

**修改的文件**:
- `app/models/approval.py` - 添加超时字段
- `app/services/approval_timeout_service.py` - 新建超时处理服务
- `app/services/audit_service.py` - 添加超时审计事件
- `scripts/check_approval_timeout.py` - 定时任务脚本
- `config.yaml` - 添加超时策略配置

**配置示例**:
```yaml
approval:
  timeout_days: 30
  timeout_strategy: "notify_only"  # 可选: auto_approve, auto_reject, escalate
  timeout_reminders:
    enabled: true
    remind_before_days: [7, 3, 1]
```

**使用方法**:

class DocumentDetailResponse(DocumentBase):

    id: UUID
    status: DocumentStatus
    status_display: str = Field(..., description="状态显示名称")
